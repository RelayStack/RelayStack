## Services

- **Websites** — Astro + Cloudflare. Static HTML, sub-second loads, nothing to maintain monthly.
- **Local SEO** — Google Business Profile, one page per service and city, `LocalBusiness` / `Service` JSON-LD, sitemap and indexation.
- **AI search visibility (GEO)** — `llms.txt` and quotable structure so ChatGPT, Perplexity and AI Overviews can read and cite the site.
- **Performance** — Core Web Vitals budgets, image pipelines, edge caching.
